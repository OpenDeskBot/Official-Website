# 驱动嘴型与插值算法说明

## 1. 音素时间戳如何得到

- 使用 FastSpeech2 的 `d_outs`（每音素预测帧数）作为时长基础。
- 秒换算公式：

`duration_sec = duration_frames * (hop_samples / sample_rate)`

其中：
- `sample_rate` 与 `hop_samples` 来自模型配置。
- 每段最终包含 `start_sec` / `end_sec` / `duration_sec`。

## 2. 音素到视素（17类）映射

基础流程：

1. 规范化音素字符串（小写、去尾数字）
2. 用规则表映射到 17 视素 key：

`REST/EE/EH/AH/AO/AW/OH/OO/OU/BMP/CHJH/FV/R/L/N/KG/S`

## 3. 实时驱动嘴型

按音频播放时钟 `t` 查找当前段：

`start_sec <= t < end_sec`

得到当前 `phone`，映射成 `viseme_key`，取目标参数：

`target = {w,h,r,teeth,tongue}`

## 4. 插值算法（平滑）

逐帧插值更新：

`display = display + alpha * (target - display)`

项目中各参数分别执行：
- `w/h/r`
- `teeth/tongue`

这样可避免嘴型瞬切抖动。
